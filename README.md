# Учёт объёмов дорожных работ — МУАД АК «АЛРОСА» (ПАО)

Веб-приложение для ежедневного учёта выполненных объёмов работ по дорожным участкам,
формирования месячных сводов, закрытия периодов и подготовки отчётных презентаций.

Работает как обычная HTML-страница: **без установки, без сервера и без интернета**.
Достаточно открыть файл в браузере.

---

## Быстрый старт

1. Откройте `dist/МУАД_Учёт_объёмов_работ.html` в браузере (двойной клик по файлу).
2. Войдите администратором: в списке выберите «Администратор системы», пароль `muad-admin`.
3. Раздел **Планы по участкам** → перетащите файл плана (примеры — в папке `templates/`) →
   выберите месяц → «Загрузить выбранные».
4. Раздел **Участки и доступы** → смените пароли администратора и участков,
   сообщите пароли ответственным.
5. Ответственный входит под своим участком и вносит объёмы в разделе **Внести объёмы**.

Пароли по умолчанию: участок — `<код латиницей>-2026` (например, `ldu-2026`, `du2-2026`,
`mdu-2026`, `du6-2026`, `du8-2026`, `udu-2026`, `ukdu-2026`); администратор — `muad-admin`;
руководство (только просмотр) — `muad-view`. **Смените их при первом входе.**

## Роли и возможности

### Ответственный за участок
| Раздел | Назначение |
|---|---|
| Обзор | План/факт/выполнение за месяц, календарь заполненных и пропущенных дней, сведения об участке |
| Внести объёмы | Ввод факта **за день** или **за неделю**; плановое значение дня подсказкой в ячейке; добавление внеплановых видов работ |
| Месячная таблица | Вся таблица «виды работ × дни». Просмотр, затем кнопка **«Редактировать»** открывает таблицу целиком; изменённые ячейки подсвечиваются до сохранения |
| Свод за месяц | План, факт, отклонение, % выполнения по видам работ; текущий и предыдущие месяцы; динамика за три месяца; выгрузка в Excel и печать |
| Закрытие месяца | Автоматическая проверка (5 контролей), комментарий к отклонениям, кнопка **«Закрыть месяц»**. После закрытия данные не редактируются; можно запросить переоткрытие |
| Передача данных | Выгрузка пакета данных за месяц для передачи администратору (если рабочие места не связаны общей базой) |
| Пароль и профиль | Смена пароля |

### Администратор
| Раздел | Назначение |
|---|---|
| Обзор по управлению | Сводные KPI за месяц, таблица по всем участкам, выполнение по видам работ, статусы закрытия |
| Своды и выгрузки | Произвольный период и фильтр по участку; вкладки «По участкам», «По видам работ», «Помесячно», «Детализация»; выгрузка в Excel |
| Отчёты и презентации | Формирование презентации за любой период: предпросмотр на экране и выгрузка `.pptx`; журнал сформированных отчётов |
| Планы по участкам | Загрузка планов (перетаскиванием, несколько файлов сразу), автоопределение участка и месяца, предпросмотр, замена ранее загруженных планов в любой день |
| Статусы периодов | Матрица «участки × месяцы», закрытие и переоткрытие периодов, обработка запросов участков |
| Участки и доступы | Справочник участков, ответственные, штат, обслуживаемые дороги, пароли, псевдонимы для распознавания файлов |
| Справочник работ | Единый перечень видов работ и единиц измерения — обеспечивает сведение данных разных участков |
| Данные и копии | Приём пакетов от участков, резервное копирование и восстановление базы, удаление данных за период |
| Журнал действий | Кто, когда и что изменил; поиск и выгрузка в Excel |

### Руководство
Просмотр обзора, сводов, отчётов и статусов периодов без права изменения данных.
Доступ можно отключить в разделе «Участки и доступы».

## Предварительный и окончательный отчёт

* Пока хотя бы один участок не закрыл период, отчёт формируется как **предварительный**
  (помечается на титульном слайде и в колонтитуле каждого слайда).
* Когда **все** выбранные участки закрыли **все** месяцы периода, становится доступен
  **окончательный** отчёт.
* Состав презентации: титул → ключевые показатели → выполнение по участкам →
  динамика (по месяцам либо по дням внутри месяца) → выполнение по видам работ →
  отдельный слайд по каждому участку → зоны внимания и выводы → статус закрытия с подписями.

## Форматы файлов планов

Планы загружаются одним файлом с листами по участкам либо отдельными файлами —
**названия файлов и листов произвольные**. Участок определяется автоматически
по названию листа, имени файла или содержимому первых строк; при необходимости
выбирается вручную из списка.

Поддерживаются четыре разновидности (примеры — в папке `templates/`, описание — в
`templates/README.md`):

1. **Дни по горизонтали** (основной): строки — виды работ, колонки — дни месяца.
2. **Отдельный файл на участок** — та же структура, произвольное имя файла.
3. **Итог за месяц без разбивки по дням** — система распределяет объём по дням.
4. **Транспонированный** — дни по вертикали, виды работ по горизонтали.

Строка без числовых значений и без единицы измерения трактуется как заголовок
объекта/контракта (например, «Основной контракт "Мухтуя"»), строки «Итого»/«Всего»
пропускаются. Расхождение суммы по дням с колонкой «Итого» показывается как замечание
до загрузки.

Готовый шаблон с текущими планами можно выгрузить кнопкой «Скачать шаблон».

## Выгрузки

| Что | Формат | Где |
|---|---|---|
| Свод участка за месяц (свод + факт по дням + план по дням) | `.xlsx` | Ответственный → Свод за месяц |
| Общий свод за период (по участкам, по видам работ, помесячно, лист на каждый участок) | `.xlsx` | Администратор → Своды и выгрузки |
| Отчётная презентация | `.pptx` | Администратор → Отчёты и презентации |
| Журнал действий | `.xlsx` | Администратор → Журнал действий |
| Пакет данных участка / резервная копия базы | `.json` | Передача данных / Данные и копии |

Файлы `.xlsx` и `.pptx` формируются по стандарту OOXML и открываются в **Р7-Офис**,
MS Excel / PowerPoint, LibreOffice и «МойОфис».

## Хранение данных — важно

Данные хранятся в **локальном хранилище браузера того рабочего места**, где ведётся учёт.
Это позволяет работать без сервера, но накладывает ограничения:

* данные **не синхронизируются** между компьютерами автоматически;
* очистка истории и данных браузера **удалит базу**;
* режим «инкогнито» не сохраняет данные между сеансами.

Как с этим работать:

* **Один компьютер в управлении.** Все участки вносят данные на общем рабочем месте —
  ничего дополнительно делать не нужно.
* **Несколько рабочих мест.** Участок выгружает пакет (раздел «Передача данных»),
  администратор загружает пакеты в разделе «Данные и копии» — данные объединяются.
* **Резервное копирование.** Администратор регулярно выгружает копию базы
  («Данные и копии» → «Выгрузить копию») и хранит её на сетевом диске.

Разграничение доступа по паролям рассчитано на разделение ролей внутри управления,
а не на защиту от целенаправленного взлома: приложение выполняется в браузере
пользователя. Пароли хранятся в виде хэша SHA-256 с солью, в открытом виде не сохраняются.

Для полноценной многопользовательской работы (общая база, права, журналирование на
сервере) потребуется серверная версия — текущая структура данных к этому подготовлена.

## Условные единицы в итогах

Виды работ измеряются в разных единицах (10 000 м², 10 км, 1 000 м², 100 м² и др.).
Поэтому:

* **по каждому виду работ** план, факт, отклонение и процент считаются в натуральных
  единицах и корректны;
* **итоговые строки** по участку и управлению приводятся в «усл. ед.» — это справочная
  сумма разнородных величин, нужная для общей оценки динамики. В отчётах и выгрузках
  это оговорено сноской.

## Требования

Браузер с поддержкой `CompressionStream` / `DecompressionStream`:
Chrome/Edge/Яндекс.Браузер 80+, Firefox 113+, Safari 16.4+.
При запуске приложение само проверяет окружение и предупреждает о несовместимости.
Интернет не требуется — внешних библиотек нет.

## Состав репозитория

```
index.html                    приложение (режим разработки, модули подключаются отдельно)
dist/МУАД_Учёт_объёмов_работ.html   автономная сборка — один файл, его и передают на рабочие места
assets/css/app.css            оформление
assets/js/
  zip.js          чтение и запись ZIP (на нативных Compression/DecompressionStream)
  xlsx.js         чтение и запись книг Excel
  pptx.js         формирование презентаций
  core.js         модель данных, хранилище, авторизация, расчёты
  ui.js           компоненты интерфейса и маршрутизация
  templates.js    шаблоны файлов планов
  planimport.js   распознавание загружаемых планов
  reports.js      своды, презентации, выгрузки в Excel
  views-site.js   экраны ответственного за участок
  views-admin.js  экраны администратора
  app.js          вход в систему и каркас
templates/                    примеры форматов планов по участкам МУАД
tools/                        сборка, генерация примеров, автотесты
```

### Сборка и проверка

```bash
node tools/build.js            # собрать автономный файл в dist/
node tools/make-templates.js 2026-01   # пересоздать примеры планов на месяц
node tools/test-import.js      # проверить распознавание всех форматов планов
node tools/e2e.js              # сквозной тест в браузере (нужен playwright-core и Chromium)
```

Внешних зависимостей у приложения нет: чтение и запись `.xlsx` и `.pptx`,
хэширование паролей и построение диаграмм реализованы в самом проекте.
