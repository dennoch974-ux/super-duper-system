# Примеры форматов файлов плана

Файлы в этой папке — рабочие образцы для загрузки в разделе **Планы по участкам**.
Данные взяты из годовой программы работ участков МУАД и распределены на январь 2026 года
по сезонному профилю (зимнее содержание, летнее содержание, ремонт).

Имена файлов и листов **произвольные** — участок определяется автоматически.

| Файл | Формат | Что демонстрирует |
|---|---|---|
| `ФОРМАТ-1_План_МУАД_все_участки_2026-01.xlsx` | дни по горизонтали | Один файл, лист на каждый участок (ЛДУ, ДУ-2, МДУ, ДУ-6, ДУ-8, УДУ, УКДУ) — основной рекомендуемый вариант |
| `ФОРМАТ-2_План ЛДУ январь 2026 (отдельный файл).xlsx` | дни по горизонтали | Отдельный файл на участок, участок определяется по листу и имени файла |
| `ФОРМАТ-2_plan_mirninsky_01-2026.xlsx` | дни по горизонтали | То же, но имя файла на латинице — распознавание всё равно срабатывает |
| `ФОРМАТ-3_План ДУ-6 (итог за месяц, без дней).xlsx` | итог за месяц | План без разбивки по дням: система распределит объём по дням сама |
| `ФОРМАТ-4_План УКДУ (дни по вертикали).xlsx` | транспонированный | Дни по вертикали, виды работ по горизонтали |

## Структура основного формата

```
A1  АК «АЛРОСА» (ПАО) · Мирнинское управление автомобильных дорог
A2  План производства работ на месяц
A3  Участок:   Ленский дорожный участок (ЛДУ)
A4  Месяц:     Январь 2026
A5  (пустая строка)
A6  Вид работ | Ед. изм. | 1 | 2 | 3 | … | 31 | Итого за месяц
A7  Основной контракт "Мухтуя"                     ← заголовок объекта
A8  Очистка дороги от снега | 10 000 м² | 43,95 | … | 1 362,47
…
    ИТОГО по участку                               ← служебная строка, пропускается
```

Правила распознавания:

* **шапка с днями** ищется автоматически — подойдут числа `1…31`, даты или записи вида `01.01`;
* **строка без чисел и без единицы измерения** считается заголовком объекта или контракта;
* строки, начинающиеся с «Итого», «Всего», «В том числе», пропускаются;
* пустая ячейка или `0` означают, что работа в этот день не планируется;
* если сумма по дням расходится с колонкой «Итого за месяц», перед загрузкой выводится замечание;
* колонки «Вид работ» и «Ед. изм.» определяются по заголовкам либо по содержимому;
  если единицы не указаны, они берутся из справочника работ.

Перед загрузкой каждый лист можно открыть в предпросмотре и убедиться, что распознаны
нужный участок, месяц, состав работ и объёмы.
